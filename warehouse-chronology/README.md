# Хронологія — аналіз журналу складу

Python-скрипт для аналізу подій складу за період **13.10.2026 23:00 — 14.10.2026 04:00**, сортування записів за повним часом і звірки з інвентаризацією.

## Файли
- `analyze.py` — скрипт аналізу журналу й опису складу.
- `хронологія.txt` — попередня хронологія, відновлена зі скріншотів.
- `висновок.txt` — попередній висновок з посиланнями на часові позначки.

## Запуск
Потрібен Python 3 (сторонні бібліотеки не потрібні). Покладіть оригінальні `hub_log.txt` і `inventory_recovered.txt` у цю папку, тоді запустіть:

```bash
python3 analyze.py hub_log.txt inventory_recovered.txt
```

## Обмеження
Початкові файли доступні лише на часткових скріншотах; тому наявні хронологія й висновок є **попередніми**. Для повного результату та підтвердження розбіжностей потрібні оригінальні файли. Пошкоджені записи не можна автоматично вважати достовірними.
